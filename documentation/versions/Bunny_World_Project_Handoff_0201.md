# BunnyWorld project handoff — 0.2.0.1

The current standalone Windows game is 0.2.0.1, based on 0.2.0. This is a private project distinct from the user's Millennium Dawn submod. The intended delivery is a complete Windows ZIP that can be extracted and run without installing Godot. The engine is Godot 4.5.1, GDScript, GL Compatibility. Source and Windows deliverables accompany each patch.

The user tests every version from a new campaign and explicitly does not want old-save compatibility or migration unless they request it. Preserve same-version saving. Current scenario ID: bunny_world_2000_0_2_0_1; starting-world schema 8 / save schema 9. Version number 0.2.0.1 is deliberate, leaving the planned larger 0.2 patches intact.

World: 223 countries, 1,235 States, 40,031 provinces and 6,144,737,528 residents. Province/country identities, starting ownership, rights and country population totals are retained. The accepted map includes corrected country shapes, reduced remote province density, Karafuto and North/South Chishima handling, lake exclusion and a vector Vatican footprint. Province populations derive from year-2000 GHSL estimates reconciled to national totals. Whole urban provinces include countryside; rural provinces share one remainder pool per State. There are 2,220 urban provinces, 1,557 groups and 1,735 linked city markers.

0.2.0 introduced age, religion, education and economic-activity profiles, finances, icon-based controls, World Ledger and a tension baseline. Demographic source estimates and national-to-State assumptions are retained in data and documentation. There is no live population growth yet. Political framework and patch roadmap are bundled; do not invent save migration or advance unrelated politics without authorization.

0.2.0.1 rendering: resident ESA CCI year-2000 land-cover families, a regional colour layer, NOAA ETOPO elevation, eight fixed aerial material layers and world-anchored triplanar texture projection. GPU compression/mipmaps are built offline into assets/materials/terrain_materials.bwm (about 22.4 MB). No geographic JPEG streaming tiles remain. Category weights blend across biome boundaries. A single immutable 192 x 144 close-up grid changes geographical coordinates and elevation on the GPU. The CPU picker uses the shared prepared relief. Keep globe seams, pole mapping, terrain tilt and border alignment correct.

Startup loads world/interface data, terrain, city meshes and graphics behind a progress screen. All 2,260 city clusters and eight landmarks are prepared once and retained; view updates show/hide cached meshes. Representative building count is 55,296 globally, capped at 1,024 nearby instances and 64 active clusters, with at most 200 per whole metropolitan group. Buildings/landmarks are exactly 3x their previous display scale. They fade in as close-zoom tilt begins. Landmark text is removed; city labels remain. The scenery toggle persists.

Waterways: selected Natural Earth major rivers; Suez and Panama canals; Bosporus and Dardanelles. Restored Black Sea (240) and Marmara (241) zones connect through reciprocal passage links to the world ocean. Inland lakes remain excluded. Narrow passages use matching vector centre lines for GPU water fill and CPU picking, plus terrain-following ribbons for readability; the underlying province atlas is retained. Passage navigation/control is a later gameplay system.

UI: national/State demographics displays all four charts in a 2x2 grid, without visible source paragraphs. Useful age denominators and hover counts remain. Find place / Ctrl+F supports countries, States, cities, metro groups and landmarks. Top-left flag opens player controls. Baseline political power is 100, stability 65%, war support 50%. Existing map modes, sounds, save/load and debug controls remain.

Validation and limitations are in TEST_RESULTS.md. Inspect the final exported Windows PCK with a real Compatibility renderer, check startup, country focus/picking, rapid travel/revisits, chart layout at minimum size, scenery scale/caps and water connections. Native Windows testing on the user's PC remains necessary. Sources are sampled/modelled, not cadastral or exact local census boundaries. Do not promise perfect performance on untested hardware.
