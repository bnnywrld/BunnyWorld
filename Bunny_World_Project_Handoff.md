# BunnyWorld 0.2.0.7 handoff

Current development baseline: `main`, after 0.2.0.6 was promoted at the user's request. Workflow: implement and run focused technical checks, publish source/prepared resources to GitHub, and have the user perform native Windows visual/performance tests in Godot. Export a Windows executable when requested or at a release milestone.

Geography now uses strict MD country State budgets, real administrative geometry and MD-like province density: 223 retained countries; 1,405 States; 13,261 land provinces. The MD reference contains 1,250 States and 13,221 land provinces excluding dummy ID 0, sea and lake definitions. Every country is within MD..floor(1.2*MD), except recorded +1 small-country geographic exceptions. Natural Earth subdivisions supply geometry; MD names/centres guide grouping and density without copying distorted boundary shapes.

All 99 Natural Earth disputed/breakaway source identities map to protected State coverage. Some nested/adjacent feature identities share States to respect country caps. Preserve current January-2000 owners/starting rights, including Ukraine's Crimea/Donetsk/Luhansk coverage. These future-dispute boundaries do not implement later events or activate disputes at start. GEOGRAPHY_COUNTRY_COUNTS.md documents counts and special groupings.

Run Prepare_BunnyWorld.bat after pulling with Godot closed. It restores matching resources, automatically replaces known older generated border files, and checks the map/data/border bundle and project version. It protects unknown custom resource edits. Godot 4.5.1 Standard, GL Compatibility. No export templates required for editor tests.

Current source/data preserve national population/building totals and the existing interface, terrain, camera and scenery architecture. Local demographic refinement, physical graphics and old-save migration remain deferred. Tests always start fresh campaigns. See DEVELOPMENT.md for the ordered generation pipeline, TEST_RESULTS.md for actual checks, and BUILD_INFO.json for source identity/limits.
